# Release Notes v1.0.0

Production release of PyStreamFlow.

Highlights:
- Stable core with backpressure, health checks, retries
- Shared web server for multiple inputs
- MCP server for AI agents
- Live view API
- Docker multi-stage build
- Observability: metrics, structured logs
- CI/CD, docs, tutorials

Breaking changes: none

Upgrade: docker compose pull && up -d
