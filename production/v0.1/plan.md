project goal:
a python based modern node graph editor for stream flow routing
input nodes can be sub streams , generators,logs,shell sessions,python scripts,files,pipes,processes,sockets,web input,stdio in general.
output nodes can be sub streams , files,pipes,processe,logs,sockets,web output,stdio in general.
modifier nodes include grepping,merging of inputs , forking of outputs,modifying streams with templates,triggers ,bool operations,number operations,tokenizer,json extraction and export,scripts,process execution etc
easy wiring of nodes.
custom sub graphs integration (easy setup of inputs/outputs)
workflow loading and saving (workflow node to access other workflows)


features:
 a fully featured local web api + node editor 
 local access via CLI command interface
 on the fly rerouting of every connection of the graph.
 yaml configuration 
 daemon mode
 running in a docker container
 packages available
 user friendly documentation
 tutorials
