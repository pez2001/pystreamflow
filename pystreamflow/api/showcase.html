PyStreamFlow Showcase

Production-ready stream flow node graph editor

Live Demo

Open the editor: /ui

Import demo_workflow.yaml to see a complete pipeline with Web Input, Text, Numeric, Boolean, Encoding, LLM and Log Output nodes.

Web Input

POST to /in/{id} on port 8080. Multiple instances supported.

Text Nodes

Upper, Lower, Trim, Replace, Substring, Reverse, Title, Strip, Split, Join

Numeric Nodes

Add, Sub, Mul, Div, Mod, Pow, Min, Max, Clamp, Round, Abs

Boolean Logic

And, Or, Not, Xor, Nand, Nor, Xnor

Encoding

EncodingConvertNode for charset conversion

LLM

LM Studio connection node with OpenAI compatible API

Live View

/nodes/{id}/last shows last items passed through

MCP Server

AI interaction at /mcp/tools and /mcp/call

Quick Start

docker compose up -d
# API http://localhost:8000
# UI http://localhost:8000/ui
# Web inputs http://localhost:8080
# MCP http://localhost:9000/mcp/tools

CLI Pipe Demo

echo '{"msg":"hello"}' | pystreamflow pipe web_in

Tail Demo

pystreamflow tail log_out
